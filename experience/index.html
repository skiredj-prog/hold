The operating model

One mandate. Three accountable layers.

The agent proposes within a bounded mission. The enforcement boundary owns consequences. The evidence outlives both.

01 · AUTHORITY
Habilitation

Defines mission purpose, scope, budget, expiry, available tools, and when the agent must return to a human.

02 · ENFORCEMENT
Execution kernel

Evaluates consequential proposals before dispatch. Prevents equivalent repeats and preserves unknown external outcomes.

03 · ACCOUNTABILITY
Evidence Envelope

Captures decisions, authority replies, receipts and unresolved states for inspection and deterministic reconstruction.
