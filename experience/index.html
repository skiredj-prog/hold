Technology roles · explicit attribution

Meta supplies the model and messaging channel. HOLD governs execution.

These are distinct components, with distinct responsibilities and evidence.

META · OPEN-WEIGHT MODEL
Llama 3.2 — agent reasoning

Used in the frozen E1-A6 experiment and available in optional local Ollama mode. The current default demonstration uses a scripted agent, not Llama inference. Model reasoning does not enforce external effects.

HOLD · INDEPENDENT GOVERNANCE
Habilitation + execution kernel

The authority boundary, deterministic checks, reconciliation and evidence are HOLD components, not properties claimed of the model.

META · WHATSAPP CLOUD API
Human decision relay

Optional live delivery and signed webhook replies when configured. This run uses a simulated relay; no phone interaction is implied.

The operating model

One mandate. Three accountable layers.

The agent proposes within a bounded mission. The enforcement boundary owns consequences. The evidence outlives both.

01 · AUTHORITY
Habilitation

Defines mission purpose, scope, budget, expiry, available tools, and when the agent must return to a human.

02 · ENFORCEMENT
Execution kernel

Evaluates consequential proposals before dispatch. Prevents equivalent repeats and preserves unknown external outcomes.

03 · ACCOUNTABILITY
Evidence Envelope

Captures decisions, authority replies, receipts and unresolved states for inspection and deterministic reconstruction.
